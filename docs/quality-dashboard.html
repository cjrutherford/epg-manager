How this stays honest

npm run css:audit, npm test, the Playwright projects (e2e, tv, visual) and Lighthouse are the sources. A metric is only marked pass when a test or a signed scorecard supports it; the human research rows stay empty until the sessions happen. Regenerate after every release and attach the page to the release notes.
